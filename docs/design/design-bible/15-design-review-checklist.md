# Design Review Checklist

Every screen must pass this checklist before approval.

---

## Purpose

Does this screen have one clear purpose?

YES / NO

---

## Primary Action

Is there exactly one primary action?

YES / NO

---

## Hierarchy

Can users understand the screen in under 3 seconds?

YES / NO

---

## Mobile

Can every important action be reached with one thumb?

YES / NO

---

## Consistency

Does the screen reuse existing components?

YES / NO

---

## Navigation

Is navigation predictable?

YES / NO

---

## Gameplay

If this is a gameplay screen:

Does gameplay occupy most of the screen?

YES / NO

---

## Accessibility

Readable text?

Enough contrast?

Large touch targets?

YES / NO

---

## Content

Friendly?

Short?

Clear?

YES / NO

---

## Animation

Purposeful?

Not distracting?

YES / NO

---

## Performance

Can this screen render smoothly on mobile?

YES / NO

---

## Empty State

Defined?

YES / NO

---

## Loading State

Defined?

YES / NO

---

## Error State

Defined?

YES / NO

---

## Expansion

Can future features fit naturally?

YES / NO

---

## Final Question

Does this screen make players want to play another round?

If the answer is NO,

revise the screen using existing Design Bible components until it does.

Do not redesign the design language to fix this — see "Never Do These" in CLAUDE.md.
