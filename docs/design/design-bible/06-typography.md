# Typography

## Philosophy

Typography should disappear.

Players should read instantly.

Never force users to decode text.

---

# Font Style

Use a modern sans-serif.

Characteristics

- Friendly
- Rounded
- Highly readable
- Mobile optimized

Avoid

- Serif
- Fantasy
- Pixel font
- Script font

Display fonts may be used ONLY for logo.

---

# Hierarchy

Display

Used for

- Splash
- Logo
- Event title

Heading

Used for

- Screen title
- Dialog title

Title

Used for

- Card title
- Section title

Body

Used for

- Description
- Instructions

Caption

Used for

- Metadata
- Time
- Version
- Hint

---

# Text Alignment

Default

Left aligned.

Centered

Only for

- Empty states
- Splash
- Result
- Dialog

Avoid justified text.

---

# Text Length

Short.

Simple.

Friendly.

Never write paragraphs inside cards.

---

# Numbers

Scores

Timers

Levels

Should be visually distinct.

Players must recognize numbers immediately.

---

# Emphasis

Prefer

Weight

Instead of

Uppercase

Prefer

Spacing

Instead of

Decorative typography.

---

# Button Text

Use verbs.

Examples

Play

Continue

Retry

Join

Save

Avoid

Click Here

Press

Submit

---

# Tone

Simple.

Friendly.

Encouraging.

Never robotic.
