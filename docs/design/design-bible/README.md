# My Lane Design Bible

## Overview

This directory contains the official UI/UX design documentation for My Lane.

Every screen, component, interaction and future feature must follow this Design Bible.

The purpose is to keep the entire product visually and functionally consistent even as new games, new developers and new AI tools are introduced.

---

## Design Goal

My Lane is a gamified brain training platform.

It is NOT:

- an educational app
- an IQ test
- a productivity dashboard
- a casino game

It IS:

- fun
- relaxing
- rewarding
- competitive (optional)
- easy to understand
- easy to expand

---

## Design Priority

1. Gameplay First
2. Mobile First
3. One Primary Action
4. Consistency
5. Accessibility
6. Simplicity
7. Delight

## AI Usage

When using ChatGPT, Claude, Cursor, Gemini or any AI Designer:

- Read the Design Bible first.
- Never invent a new visual style.
- Never introduce new components unless requested.
- Follow the existing design language.
- Maintain consistency across every screen.

---

## Future Expansion

Current games (Sequence Memory, Number Memory, Alphabet Memory, Grid Memory) already ship on this design system.

The design system must also support future games such as:

- Pattern Memory
- Simon
- Memory Matrix
- Spatial Memory
- Corsi Block
- Dual N-Back
- Visual Memory
- Audio Memory
- Typing Memory
- Daily Challenge

without redesigning the entire product.

This list must stay in sync with the Future Games list in [`00-project-overview.md`](00-project-overview.md).
