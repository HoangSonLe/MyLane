# Visual Language

## Design Direction

Memory Arena follows the design language:

Modern Cozy Brain Game

The interface combines:

- Modern Product Design
- Mobile Games
- Indie Games
- Brain Training

---

## Inspiration

Inspired by

- Human Benchmark
- Lumosity
- Elevate
- Nintendo
- Supercell

Not copied.

Only inspired.

---

## Visual Feeling

The interface should feel:

Modern

Friendly

Soft

Focused

Comfortable

Premium

Minimal

Playful

---

## Avoid

Do NOT use:

Glassmorphism

Heavy Neumorphism

Steampunk

Wood texture

Vintage UI

Fantasy RPG

Cyberpunk overload

Enterprise dashboard

Crypto / NFT aesthetic

Medical application

Educational software

---

## Shape Language

Rounded corners

Large cards

Simple geometry

Clean layouts

Soft shadows

Minimal borders

---

## Surfaces

Background

↓

Dark neutral

Surface

↓

Slight elevation

Primary

↓

Clean

Readable

Accent

↓

Used only to attract attention

---

## Information Density

Medium.

Never crowded.

Never empty.

---

## Navigation

Simple.

Predictable.

Bottom navigation for primary destinations.

Back button for secondary flows.

---

## Card Design

Cards represent content.

Not decoration.

Cards should contain:

Title

Description

Action

Optional metadata

---

## Icons

Simple.

Rounded.

Consistent stroke.

Readable at small sizes.

---

## Illustration

Minimal.

Only when helpful.

Do not decorate every screen.

---

## Visual Focus

Every screen should have exactly one visual anchor.

Examples

Home

↓

Play

Game

↓

Gameplay Area

Result

↓

Final Score

Profile

↓

Player Information

---

## Overall Experience

The UI should disappear.

The gameplay should remain.
