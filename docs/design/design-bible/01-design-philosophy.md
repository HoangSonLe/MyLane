# Design Philosophy

## Core Philosophy

Gameplay comes before interface.

The interface exists to support gameplay, not replace it.

---

## Principle 1

Game Before Dashboard

The user opens Memory Arena because they want to play.

Not because they want statistics.

Statistics are secondary.

Gameplay is primary.

---

## Principle 2

One Primary Action

Every screen should have exactly one dominant action.

Examples

Home

→ Play

Game Select

→ Choose Game

Result

→ Play Again

Profile

→ Edit Profile

Never make users choose between multiple equally important actions.

---

## Principle 3

Reduce Cognitive Load

Memory games are already mentally demanding.

The interface should never become another challenge.

Keep layouts clean.

Keep navigation predictable.

Keep interactions simple.

---

## Principle 4

Progress Without Pressure

Players should feel improvement.

Players should never feel judged.

Celebrate progress.

Avoid excessive comparison.

Leaderboard exists.

It is not the center of the experience.

---

## Principle 5

Gameplay Dominates

During gameplay:

80% of the screen should belong to the game.

HUD should stay minimal.

Menus should disappear.

Notifications should never interrupt gameplay.

---

## Principle 6

Consistency

Every screen should reuse existing components.

Avoid creating one-off UI.

The design system should grow naturally.

---

## Principle 7

Delight

Small animations.

Positive feedback.

Gentle sounds.

Achievement moments.

These create motivation.

Not giant rewards.

---

## Principle 8

Mobile First

Design for phones first.

Desktop adapts from mobile.

Never design desktop first.

---

## Principle 9

Expandable

Future games should fit naturally into the same interface.

The design should not depend on one specific game.

---

## Principle 10

Invisible UI

The best interface is the one users stop noticing.

Players should focus on remembering.

Not learning the interface.
