# Accessibility

## Philosophy

Memory Arena should be playable by everyone.

Accessibility is a requirement.

Not an optional feature.

---

# Text

Readable.

Simple.

High contrast.

Avoid tiny fonts.

---

# Touch Targets

Large enough for thumbs.

Avoid tiny buttons.

---

# Color

Never rely only on color.

Always combine with

Text

Shape

Icon

Animation

---

# Motion

Respect Reduced Motion.

Animations should never be required.

---

# Sound

Every sound should have a visual alternative.

---

# Haptic

Optional.

Never mandatory.

---

# Contrast

Maintain readable contrast across all themes.

---

# Keyboard

Desktop should support keyboard navigation.

---

# Screen Reader

Interactive components require labels.

---

# Focus

Visible.

Consistent.

Predictable.

---

# Error Messages

Explain

What happened

How to fix it

---

# Color Blindness

Support

Protanopia

Deuteranopia

Tritanopia

Never use red vs green alone.

---

# Flashing

Avoid flashing animations.

Especially during gameplay.

---

# Accessibility Goal

Every player should be able to enjoy the game comfortably.
