# Project Overview

## Product Name

My Lane

---

## Vision

Build the best browser-based memory training platform that feels like a game instead of a test.

---

## Mission

Help players improve memory, attention and cognitive skills through enjoyable gameplay.

The platform should encourage continuous improvement while avoiding unnecessary stress.

---

## Target Audience

Primary

- Students
- Office workers
- Gamers
- Competitive players

Secondary

- Teachers
- Parents
- Researchers

---

## Platforms

Version 1

- Mobile Web
- Desktop Web

Future

- PWA
- Android
- iOS

---

## Core Gameplay

Players train different memory skills through independent mini games.

Each game measures different cognitive abilities.

---

## Current Games

- Sequence Memory
- Number Memory
- Alphabet Memory
- Grid Memory

---

## Future Games

- Pattern Memory
- Simon
- Memory Matrix
- Spatial Memory
- Corsi Block
- Dual N-Back
- Visual Memory
- Audio Memory
- Typing Memory
- Daily Challenge

---

## Product Principles

The game should always feel:

- Fun
- Friendly
- Relaxing
- Rewarding
- Competitive (optional)

It should never feel like:

- School homework
- IQ testing
- Medical software
- Enterprise dashboard

---

## Success Criteria

Players should naturally think:

"I'll play one more round."

instead of

"I've finished today's task."
