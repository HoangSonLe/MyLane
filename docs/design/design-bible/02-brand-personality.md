# Brand Personality

## Brand Position

My Lane is a modern brain-training game platform.

It is designed to help players improve cognitive skills while enjoying short and rewarding game sessions.

It should never feel like an exam.

---

## Brand Archetype

Primary

Explorer

- Discover
- Improve
- Curiosity
- Progress

Secondary

Playmate

- Friendly
- Fun
- Encouraging
- Relaxed

Avoid

Authority

The application should never lecture users.

Avoid

Scientist

The application is not a laboratory.

Avoid

Teacher

The application is not a classroom.

## Voice

The interface speaks like a coach.

Not like a teacher.

Not like a boss.

Not like a machine.

Examples

GOOD

Ready for another round?

Nice memory!

New personal best!

Keep going!

Almost there!

Excellent recall!

BAD

Incorrect.

Game Over.

You Failed.

Error.

Mission Failed.

IQ Score.

---

## Motivation Style

Reward effort.

Reward consistency.

Reward improvement.

Never shame failure.

---

## Success Feeling

Players should leave each session thinking:

"I'm getting better."

instead of

"I'm not smart enough."
