# Screen Guidelines

## Philosophy

Every screen should have one clear purpose.

If a screen tries to do too much, split it.

---

# Standard Screen Structure

Every screen follows this hierarchy.

Header

↓

Primary Content

↓

Secondary Content

↓

Primary Action

↓

Navigation

Never change this order unless gameplay requires it.

---

# Header

Contains

- Screen Title
- Back Button (optional)
- Context Action (optional)

Never overload the header.

---

# Primary Content

The reason this screen exists.

Examples

Home

↓

Continue Playing

Game Screen

↓

Gameplay Area

Leaderboard

↓

Ranking List

Settings

↓

Configuration

---

# Secondary Content

Supports the primary content.

Examples

Statistics

Tips

Recent Activity

Friends

Achievements

---

# Primary Action

Every screen must have ONE dominant action.

Examples

Play

Continue

Save

Retry

Join

Edit

Never create two competing primary actions.

---

# Navigation

Only contains destination changes.

Never place gameplay actions inside navigation.

---

# Empty State

Every screen must define an empty state.

Examples

No Friends

No History

No Notifications

No Saved Progress

Every empty state should explain:

- What happened
- Why
- What users can do next

---

# Loading State

Every screen should define loading behavior.

Prefer Skeleton Loading.

Avoid blank screens.

---

# Error State

Every screen should define recovery.

Always provide

Retry

Reload

Back

---

# Responsive

Mobile first.

Tablet second.

Desktop last.

---

# Fold

Important information should appear without scrolling.

---

# Scroll

Prefer one vertical scroll.

Avoid nested scrolling.

---

# Section Rules

Each section should answer one question.

Player

↓

Who am I?

Game

↓

What can I play?

History

↓

What happened?

Achievements

↓

What have I earned?

---

# Home Screen

Purpose

Encourage another play session.

Not statistics.

---

# Gameplay Screen

Purpose

Support gameplay.

Nothing else.

---

# Result Screen

Purpose

Celebrate progress.

Encourage replay.

---

# Profile

Purpose

Identity

Progress

History

---

# Settings

Purpose

Configuration only.

Never mix gameplay.

---

# Leaderboard

Purpose

Comparison.

Never hide the player's own rank.

---

# Dialog

One decision.

Never multiple unrelated choices.
