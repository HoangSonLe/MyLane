# Iconography

## Philosophy

Icons support recognition.

Icons never replace clear labels.

---

## Style

Modern

Rounded

Simple

Consistent

Minimal

---

## Stroke

Consistent weight.

Never mix outline and filled icons randomly.

---

## Corner Style

Rounded.

Avoid sharp geometric icons.

---

## Size Hierarchy

Small

Medium

Large

Extra Large

Never invent random sizes.

---

## Color

Icons inherit semantic color.

Do not color icons only for decoration.

## Rules

Always pair unfamiliar icons with text.

Never create decorative icon collections.

Icons should reduce reading effort.

Not increase it.
