# Spacing & Layout

## Philosophy

Whitespace is a feature.

Not wasted space.

The interface should breathe.

---

## Grid

Use an 8-point spacing system.

Allowed spacing

4

8

12

16

24

32

40

48

64

Avoid random values.

---

## Screen Padding

Mobile

Consistent horizontal padding.

Desktop

Increase padding gradually.

---

## Vertical Rhythm

Related components

↓

Small spacing

Sections

↓

Large spacing

Maintain rhythm across all screens.

---

## Layout

Each screen should contain

Header

↓

Primary Content

↓

Secondary Content

↓

Navigation

Never mix unrelated content.

---

## Card Spacing

Internal spacing should remain consistent.

Title

↓

Description

↓

Action

Use the same spacing everywhere.

---

## Touch Targets

Every interactive component should be thumb-friendly.

Never place tiny buttons.

---

## Corner Radius

Use a consistent radius system.

Small

Medium

Large

Extra Large

Do not invent custom radius values.

---

## Shadows

Soft.

Minimal.

Used only for elevation.

Never use shadows as decoration.

---

## Borders

Use borders only when needed.

Avoid heavy outlines.

Spacing should separate components first.

Borders second.

---

## Responsive

Design mobile first.

Desktop expands.

Not the opposite.

---

## Fold

Important content should appear above the fold whenever possible.

Primary action should never require scrolling.
